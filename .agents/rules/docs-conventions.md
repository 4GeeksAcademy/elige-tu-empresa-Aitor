# Documentación

- Cada carpeta nueva lleva `README.md`; si existe versión `README.es.md`, mantenerla sincronizada.
- Describe objetivo, tecnología y cómo ejecutar, sin copiar contenido de otras empresas.
- Usa rutas reales del repo; no menciones carpetas inexistentes (por ejemplo `apps/`).

# Datos sensibles

- No commitear datos personales reales ni credenciales. Usa datos sintéticos o anonimizados.
- No pegar datos personales en prompts, logs ni mensajes de commit.
- Limitar el acceso: documenta quién puede ver cada dato.
- Las recomendaciones sobre personas son apoyo; la decisión final es humana.

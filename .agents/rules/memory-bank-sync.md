# Memory bank

- Al empezar, lee `memory-bank/projectbrief.md`, `techContext.md` y `progress.md`.
- Antes de cada commit, actualiza `memory-bank/progress.md` (hecho, pendiente, decisiones abiertas).
- Las decisiones deben alinearse con `nexova-BRIEFING.es.md`. No inventes contexto de negocio.

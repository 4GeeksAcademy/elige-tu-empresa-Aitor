# Checklist de commit

1. Cada archivo nuevo está en su ruta oficial; no hay árboles paralelos.
2. `memory-bank/progress.md` actualizado.
3. README de las carpetas tocadas actualizados.
4. Sin secretos, `.env` ni datos personales.
5. `git status` y `git diff` revisados: solo cambios de la tarea.
6. Mensaje claro, con el trailer `Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>`.
